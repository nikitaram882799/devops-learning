# Day 1: Shell and filesystem

- pwd: shows the current folder
- cd: moves to another folder
- ls, ls -la, ls -l: list files (hidden, detailed)
- cat, cat -n, cat -A, cat -s: display files
- > and >>: write to a file (replace / append)
- << 'EOF': type several lines into a file
- grep, grep -r, grep -rl: search text inside files
- find -name: search for files by name
- wc -l: count lines
- sort, uniq -c, awk: sort, count, and pick columns
- chmod: change permissions
- mkdir -p, touch, rm, rm -r: create and remove files and folders
- 2>/dev/null: hide error messages
